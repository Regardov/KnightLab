# KnightLab

Интерактивный русскоязычный тренажёр шахматной тактики. Проект работает без сборки: откройте `dist/index.html` или запустите локальный статический сервер из папки `dist`.

## Возможности

- интерактивная доска с проверкой решения и автоматическими ответами соперника;
- тематический каталог: маты, выигрыш материала, атака, защита, эндшпиль и смешанные задачи;
- фильтры по теме и сложности;
- подсказки, пояснения, серия правильных решений и дневная цель;
- локальное сохранение прогресса в браузере;
- адаптивная вёрстка для компьютера, планшета и телефона.
