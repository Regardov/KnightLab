# KnightLab

Интерактивный русскоязычный тренажёр шахматной тактики. Проект работает без сборки: откройте `dist/index.html` или запустите локальный статический сервер из папки `dist`.

## Возможности

- интерактивная доска с проверкой решения и автоматическими ответами соперника;
- 250 реальных задач: по десять позиций для каждого из 25 тематических фильтров;
- фильтры по теме и сложности;
- подсказки, пояснения, серия правильных решений и дневная цель;
- локальное сохранение прогресса в браузере;
- адаптивная вёрстка для компьютера, планшета и телефона.

## Проверка задач

Все позиции дополнительно проверяются через `chess.js` и локальный Stockfish 19: валидируется FEN, легальность позиции и каждого хода, отсутствие уже поставленного мата или пата, а также совпадение ходов игрока с лучшей линией движка на глубине 14. В опубликованном сайте Stockfish.js 19.0.1 Lite повторно анализирует начальную позицию прямо в браузере.

```powershell
cd tools\puzzle-audit
pnpm install
node audit.mjs
```

Исполняемый файл движка хранится локально в `tools/stockfish/` и не входит в публикацию сайта. При необходимости путь можно передать через переменную окружения `STOCKFISH_PATH`.

Задачи импортированы из открытой базы Lichess (CC0). Браузерная сборка Stockfish.js распространяется по GPLv3; текст лицензии включён в `dist/engine/COPYING.txt`.
